# Escape the Sun: Dubai — Android debug build

The playable GitHub Pages game remains at the repository-root `index.html`. The build copies it to `www/index.html` without changing the original.

## Automatic APK

Open **Actions → Android Debug APK → Run workflow** (or push changes to `main`). When the run succeeds, open its **Artifacts** section and download `escape-the-sun-dubai-debug-apk`. Extract the ZIP to get `app-debug.apk`. Install on Android, allowing installation from that source when prompted.

This is a **debug-signed test APK**, not a production release. The generated Android project is intentionally not committed; it is generated by Capacitor during CI. Before store publication, add persistent Android project sources, icons, splash screen, versioning, release signing and AAB distribution.

## Local development

Requires Node.js 22, Java 21 and the Android SDK.

```sh
npm ci
node scripts/prepare-web.mjs
npx cap add android
cd android
./gradlew assembleDebug
```

App ID: `com.escapethesun.dubai`. The game remains offline-capable except for external landmark images and Wikipedia links; local photo bundling is a separate task.
